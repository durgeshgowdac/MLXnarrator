# Getting Help

Stuck? Here is the quickest route to an answer.

1. **Check the [Troubleshooting section](README.md#troubleshooting)** of the README. Most setup problems (missing `ffmpeg-full`, wrong Python version, Whisper model not found, double-click launchers refusing to open) are covered there.
2. **Search [existing issues](../../issues?q=is%3Aissue)**. Someone may have hit the same wall.
3. **Ask a question** in [Discussions](../../discussions), if enabled for this repository.
4. **Found a bug?** Open an issue using the bug template and include your macOS version, chip, Python version, and the terminal output.

Please don't paste Hugging Face tokens or other secrets into issues. For security problems, see [SECURITY.md](SECURITY.md).
